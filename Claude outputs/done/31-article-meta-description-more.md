# Article meta description ends with a stray "More"

src/app/[slug]/page.tsx line ~117 builds the article meta description as truncateAtWord(stripHtml(post.excerpt.rendered), 160). WordPress auto-excerpts end with a read-more link ("[…] More" / "Read more" / "&hellip; More"), and stripHtml keeps its text, so the live description for the Torno Subito article ends "...September 22-26, 2026. More" while the excerpt Roman sees in WordPress does not.

Fix: strip the trailing read-more marker (any of "More", "Read more", "Continue reading", with the preceding ellipsis or "[…]" and surrounding whitespace, case-insensitive, at the end of the string only) before truncation, and prefer the AIOSEO / Yoast meta description field from the WP REST response when present (check what the posts endpoint exposes; if yoast_head_json or aioseo fields are returned, use their description first, else the cleaned excerpt). Do the same wherever the excerpt feeds Open Graph / Twitter descriptions or the article JSON-LD. Add a unit test for the stripping. Revalidate the article route (it is 6h cached), confirm the Torno Subito article's meta description and og:description end at "2026." and spot-check three older articles. Report the commit.
